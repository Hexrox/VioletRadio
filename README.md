## 📱 O projekcie

Violet Radio łączy nowoczesny design z prostotą obsługi. Stwórz kolekcję ulubionych stacji z Polski i świata.

### ✨ Cechy

- 🎨 Material Design 3 z Material You
- 📻 Tysiące stacji z całego świata
- 💜 Minimalistyczny design
- 🎵 **Spotify Integration** - dodawaj utwory z radia do playlisty
- 🌙 Dark mode
- ⏲️ Sleep timer
- 📱 Widget
- 🔔 Powiadomienia z kontrolkami
- 💾 Offline support

## 🎵 Violet Sync (Spotify)

**Killer feature:** Słyszysz piosenkę w radiu? Dodaj jednym kliknięciem do Spotify!

1. Radio strumieniuje z metadanymi (Artist - Title)
2. Violet Radio pokazuje przycisk 💜
3. Klik → utwór w playliście "Violet Radio Discoveries"
4. Słuchaj później na Spotify ✨

## 🛠️ Tech Stack

**Core:** Kotlin, Jetpack Compose, Material 3, Coroutines
**Audio:** ExoPlayer, MediaSession
**Network:** Retrofit, OkHttp, Room, DataStore
**Integration:** Spotify SDK, Radio Browser API
