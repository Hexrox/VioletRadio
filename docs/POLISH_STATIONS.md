## 📊 Implementation Notes

### Stream URL Status Legend

- ✅ **Verified** - URL confirmed working (as of Nov 2024)
- ⚠️ **Requires Verification** - URL may be outdated, check official source
- 🔍 **Missing** - URL not yet found, visit official website

### URL Verification Process

**For production implementation:**

1. **Test each stream URL** before adding to database
2. **Verify bitrate and codec** using media player
3. **Check for geo-restrictions** (some streams may be Poland-only)
4. **Monitor for URL changes** (streams can change periodically)
5. **Fallback to official website** if stream fails

### Getting Current Stream URLs

**Method 1: Official Website**
- Visit station's official website
- Look for "Słuchaj online" or "Listen live" button
- Inspect network traffic (F12 → Network tab) to find stream URL

**Method 2: Radio Browser API**
```bash
curl "https://de1.api.radio-browser.info/json/stations/bycountrycode/PL" \
  -H "User-Agent: VioletRadio/1.0"
```

**Method 3: Online Radio Directories**
- https://onlineradio.pl/
- https://radioport.pl/
- https://fmstream.org/index.php?c=POL

